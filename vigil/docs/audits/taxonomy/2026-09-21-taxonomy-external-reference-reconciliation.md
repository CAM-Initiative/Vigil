## Method

Each current class was reviewed against its parent-family invariant, definition, class invariant, recognition and exclusion boundaries, neighbouring-class separation, existing references, the current external-governance corpus, and both September evidence audits. Candidate relationships were adjudicated as **DIRECT**, **STRONG SUPPORTING**, **CONTEXTUAL**, **WEAK / REJECT**, or **EVIDENCE GAP**. Only DIRECT and genuinely strong STRONG SUPPORTING sources were written into canonical class records. Incident sources were not promoted merely to increase citation counts.

The review began with 33 referenced classes, 38 unreferenced classes and 54 canonical entries. It ends with 43 referenced classes, 28 explicit gaps and 63 canonical entries: ten classes gained a defensible reference, one contextual-only reference was removed, and three existing notes were corrected to state inferential limits. No Incident, Harm Impact, class definition, family placement or external-requirement record was changed.
