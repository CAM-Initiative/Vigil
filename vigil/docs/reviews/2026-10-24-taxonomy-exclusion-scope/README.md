# Explicit exclusion scope — unpublished taxonomy candidate

Date: 24 October 2026. Candidate: **v0.8.1**, based on published v0.8.0. Work lane: `agent/taxonomy-development`. This is a normative clarification proposal, not a publication or an Incident disposition.

## What changes

All **17 families, 80 selectable classes and 384 original class exclusion entries** were inventoried. The [exact before/after dispositions](EXCLUSION-DISPOSITIONS.json) retain each original string, its position in the pinned baseline, its scope decision and the class-specific review basis. Array positions are review pointers, not new immutable condition IDs.

| Original entry disposition | Count | Effect |
| --- | ---: | --- |
| Not aligned only | 164 | Defeats the adverse role for the assessed property. All positive conditions still require evidence. |
| Class scope, all results | 215 | Defeats every role, including Boundary, where that scope predicate applies. |
| Interpretive or routing note | 4 | Moved without content loss to a definition, invariant or relationship note; not an exclusion predicate. |
| Compound research/authorisation entry | 1 | Split into absent extraction-purpose scope and independently authorised acquisition. |

The candidate contains 381 exclusion strings: four notes moved out, and one compound entry split into two. No immutable family/class IDs, names, codes, membership, success/failure condition, required-recognition list, confidence threshold or example was changed. The family definitions and invariants remain unchanged. Family diagnostic routing now states its existing failure-only scope explicitly. The schema's existing exclusion description is clarified; its accepted shape and executable constraints are unchanged. No validator, builder or permanent test is modified.

Four notes were moved: FC-057's intrinsic-worth qualification, FC-067's public-availability qualification, and FC-079/082's AI-selected-objective co-occurrence advice. All remain directly in the canonical taxonomy.

FC-044 and FC-045 now state that practical direct inspection and governed protected-evidence production can coexist only for distinct independently evidenced properties or episodes. An order or attempted production does not prove completed production, correct matching or practical access. This does not prejudge INC-008.
