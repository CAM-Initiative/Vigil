### INC-095: actual malicious package, not proven recipient compromise

Mistral first-party security advisory `MAI-2026-002` (published 12 May; updated/closed 14 May 2026) confirms that `mistralai==2.4.6` PyPI import executes malicious code on Linux; the affected versions were available for hours and later removed. The advisory requests cleanup, secret rotation and log review of exposed installations; it does **not** supply verified downstream customer import counts, successful credential exfiltration, restoration costs or aggregate realised harm. The actual package compromise is preserved; impact threshold and affected persons/assets remain an evidence hold.

First party: https://docs.mistral.ai/resources/security-advisories/MAI-2026-002
