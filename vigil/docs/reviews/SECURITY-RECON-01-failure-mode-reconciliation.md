## Candidate adjudication and non-duplication

- **FM-0067:** survives. Threshold requires persistence beyond originating content, later reactivation/effect, deficient provenance/quarantine/revocation and security consequence/pathway. Excludes FM-0009 general non-revocable context, ordinary prompt injection, training poisoning and cross-user leakage.
- **FM-0068:** survives. The representation change itself launders source authority. Excludes ordinary injection, FM-0057 opaque reasoning portability, benign decoding with preserved trust and mere encryption.
- **FM-0069:** survives. The protected boundary is framework control state—configuration, checkpoint, cache, tool schema, routing, deserialised object or orchestration—not content transformation alone. FM-0022 plus FM-0068 is insufficient when untrusted data becomes control-plane state.
- **FM-0070:** survives. Local controls may individually conform while composition creates a materially different unauthorised security path. It is distinct from FM-0044’s target–action/objective admissibility rule.
