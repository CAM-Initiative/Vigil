# VIGIL Harm Impact Methodologies

This directory preserves versioned VIGIL Harm Impact Methodology artefacts.

- `VIGIL.HarmImpactMatrix.v1.0.1.json` — **current methodology**, effective 2026-09-20. Use this version for all current and new canonical Incident harm assessments.
- `VIGIL.HarmImpactMatrix.v1.0.0.json` — **retired from active use**. It is preserved unchanged as historical audit material for the earlier adjudication state and must not be used for current or new assessments.

Historical Incident review provenance may legitimately name VIGIL-HIM 1.0.0 where that review was performed under the earlier methodology. Those historical statements are evidence of the audit trail and must not be mechanically rewritten to 1.0.1.

The completed 1.0.1 corpus re-adjudication is documented in `vigil/docs/reviews/2026-09-20-vigil-him-1.0.1-corpus-readjudication.md`.
