# Provisional methodology and semantic QA recommendations

Status: **INCOMPLETE AUDIT; recommendations only.** No production methodology, schema or validator changes have been made.

The recurring error is treating rejection of a proposed class as an answer to materiality or complete coverage. INC120 E004 is the clearest current candidate: actual restricted-capability assistance needs an independent substantive test even when an available/activated control is not evidenced. INC141 E001 illustrates a different error: observable protective failure and newly retrieved primary records support existing FC083 without proof of hidden intent.

Mechanically checkable proposals:

- Require explicit independent-materiality, source locator, assessed actor/system, recommendation, confidence, uncertainty and coverage/gap-treatment fields before finalising a no-mapping disposition. A nonempty field is only structural compliance.
- Preserve the previous disposition and reasoning alongside every proposed change, pinned source/taxonomy versions and stable clause identifiers.
- Check population partitions, legacy terminology, duplicate IDs, source-reference joins, literal criterion/exclusion versions and audit-only changed paths.
- Flag generic text, unsupported universal claims, identical rationales on distinct stages and evidence-status claims that exceed recorded access. Flags require adjudication, not automatic acceptance or rejection.
- Require declared positive/negative scope and distinguish announcement, invocation, observed effect, final disposition and downstream compliance. This can detect missing fields; it cannot judge adequacy.

Substantive human/model-assisted adjudication proposals:

- Assess the original clause and episode before the prior rationale. State why the particular phenomenon matters without first asking whether a class fits.
- For a material unmatched clause, test plausible neighbouring conditions/exclusions, positive recognition where relevant, and whether the issue is evidence, overlooked coverage, narrower clarification or genuinely missing concept.
- Distinguish uncertainty that conduct occurred from uncertainty about mechanism. Do not require internal root cause where the class can recognise observable conduct and effect. Do not infer malicious model intent from generated confessions.
- Recognise actual bounded successes after failures: pauses, route disablement, delivered appeals, financial freezes, source corrections and forensic reconstruction. Do not require universal cure, all-user understanding or reversed past harm for a narrower supported invariant.
- Preserve system/actor boundaries. An external defender's observed safeguard can be separately assessed; an external context-only statement need not become a duplicate mapping on the assessed model.
- Treat an unavailable source as an access limitation, not automatic proof of no event. Record primary versus reproduction, canonical preserved account, paywall, image/video not viewed and exact evidentiary consequences.
- Cluster repeated material no-mapping propositions by mechanism and compare with existing and rejected proposals. Semantic clustering is triage; each resulting recommendation still needs source-specific reasoning and a criterion matrix.

Illustrative audit anchors: INC064 E013 (changed assessment scope); INC080 E005 (bounded repair); INC086 E004 supplement (later safe exit); INC108 E005/E006 (hidden execution versus route closure); INC120 E004 (candidate substantive assistance boundary); INC134 E001 (workflow obligation boundary); INC141 E001 (outcome versus localisation); INC153 E005 (correction propagation).

Final assurance still requires review of the remaining population, reconciliation of the original19 packets and supplements, complete proposal comparison, consolidated register and independent semantic QA. The existence of many sound retained dispositions does not establish taxonomy completeness.
