## Proposed semantic test change — pending explicit approval

1. **Current behaviour:** `test_assessment_public_prose_does_not_depend_on_internal_shorthand` applies the same taxonomy-ID and maintenance-language regexes to evidence, conclusion, significance, harm and source prose. It treats `mapped`, `unmapped` and `taxonomy gap` as maintenance language in every surface.
2. **Proposed behaviour:** Give only `vigil_assessment.governance_interpretation` a conclusion-specific rule: allow taxonomy identifiers and analytical use of `mapped`, `unmapped` and `taxonomy gap`. Continue rejecting explicit workflow/maintenance phrases there (`canonical Incident`, `classifier narrative`, `post-promotion`, `current branch`, `review pass`, and schema/taxonomy/record migration). Keep every existing restriction on all other fields, including the separate Stage 01 test.
3. **Pass/fail delta:** INC-075's `insufficient protective effect under FC-000083`, INC-064's `public-posting assessment taxonomy gap`, and INC-159's `additionally mapped as target-binding failure` would pass in the conclusion. The identical text would continue failing in `summary` and other currently guarded fields. `current branch` or `review pass` would continue failing in the conclusion. No currently accepted content would become rejected.
4. **Affected surface:** One permanent prose test and its field-specific pattern selection; Stage 05 conclusion only. No renderer, schema or generated projection change.
5. **Measured impact:** 11 diagnostics across the 10 records listed above would clear. Every currently observed match is an allowed analytical identifier/term under the proposal. Stage 01 is already clear. Full rerun is required after implementation.
6. **Repair implication:** No canonical prose rewrite, field movement, taxonomy reclassification, harm change, evidence change, provenance edit or migration is proposed. Add isolated positive/negative cases to preserve the field boundaries.
7. **Risk:** A lexical guard cannot distinguish every analytical use from internal editorial narration. The narrower rule removes these three blanket bans only from the governed conclusion; explicit workflow phrases remain guarded. It does not certify factual correctness or classification consistency, which remain governed separately.
8. **Why the test should change:** MAINTAINERS' mandatory field-to-render crosswalk describes Stage 05 as an integrated governed analytical conclusion and explicitly permits governed analytical language. The shared regex currently conflates that contract with the lay Stage 01 occurrence narrative. This is a test/field-contract mismatch, not evidence that supported canonical diagnosis should be deleted.
9. **Stop condition:** After approval, implement the narrowly scoped field rule, run it read-only and rerun required workflows. Report any remaining content failures and obtain separate approval before multi-record repair. Do not silently rewrite Incidents or change other field contracts.
